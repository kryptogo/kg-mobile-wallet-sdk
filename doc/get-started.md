# Get Started

## Clone KG\_SDK

```bash
git clone kg_SDK
```

Place the `KG_SDK` directory into the root directory of your application.

## Configure Initialization Parameters

| Parameter      | Type    | Description                                                              |
| -------------- | ------- | ------------------------------------------------------------------------ |
| `appName`      | String  | The name of your application, used to identify it in the SDK.            |
| `clientId`     | String  | Your application's client ID provided by KryptoGO.                       |
| `clientToken`  | String  | Your application's client token for authentication.                      |
| `sharedSecret` | String? | (Optional) A secret key used if a user changes devices or loses their phone. |
